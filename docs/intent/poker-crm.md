# Intent: Покерная CRM

- **Outcome:** Персональный веб-кабинет «Покерная CRM», работает локально на компьютере пользователя.
- **User:** Один пользователь, заполняет данные сам.
- **Why now:** Нужна покерная бухгалтерия: балансы румов, турниры, депозиты/выводы/переводы и долгосрочная статистика.
- **Success:** Заполнил балансы по румам → профит по сессии (по румам и суммарно); заполнил турниры → график как у SharkScope (каждый турнир влияет), календарь активности, расхождения >5% подсвечиваются с вариантами (поправить баланс / турниры / списать на казино).
- **Constraint:** Все деньги в USD. Курсы (в т.ч. PokerDom через headless-Chromium, ссылку даст пользователь) фиксируются на день и не пересчитывают прошлые дни. EUR→USD из бесплатного API.
- **Stack:** Полностью на агенте.
- **Out of scope:** Деплой, мульти-пользовательский доступ, мобильные приложения, авто-отчёты.

## Модель учета

- **Сессия** = день, когда заполнялись балансы. Профит считается по румам и суммарно (дельта баланса минус транзакции за день).
- **Баланс** — источник истины. Турниры — детализация дневного профита.
- **Транзакции:**
  - Депозит: личная карта → банкролл (+банкролл), не влияет на профит.
  - Вывод: банкролл → на карту (деньги выходят из банкролла).
  - Перевод: рум ↔ биржа/холодный кошелёк, c комиссией или без; актуализирует балансы, не влияет на профит/график.
- **Турниры:** ввод байина и результата, пустая строка в конце не считается. Связка «баланс изменился → кнопка заполнить турниры».
- **Валюты румов:** касса и турниры могут отличаться (PokerDom: касса USD / турниры RUB; RedStar: EUR/EUR).
- **Расхождения:** разница >5% между турнирной статистикой и дельтой баланса → предложить поправить баланс / турниры / списать на казино.
- **Дизайн:** минималистичный, современный, тёмные тона.

## Вкладки

1. Балансы (дашборд) — актуальные балансы по румам.
2. Сессии — день + профит по румам и общий.
3. Румы — название, валюта кассы, валюта турниров.
4. Депозиты и выводы — транзакции (депозит / вывод / перевод), сумма, комиссия, дата, комментарий.
5. Статистика — график профита (как SharkScope), календарь активности (кол-во турниров: <15 красный, 15–20 оранжевый, >20 зелёный).
