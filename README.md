# Poker CRM

Персональный локальный веб-кабинет для покерной бухгалтерии одного пользователя:
румы, балансы и сессии, транзакции (депозит/вывод/перевод/казино), импорт турниров,
статистика (график профита как в SharkScope + календарь активности), цели с дневником
и трекер привычек. Тёмный минималистичный интерфейс, подписи на русском.

## Требования

- **Node.js >= 22.5** (проверить: `node -v`). Скачать: https://nodejs.org/.
  Нужен именно 22.5+ — приложение использует встроенный модуль `node:sqlite`.
- npm (идёт в комплекте с Node.js).

Больше ничего ставить не нужно: скрипты запуска сами создадут `.env`,
установят зависимости и поднимут сервер с клиентом.

## Быстрый старт

**Windows** — запустите один файл в корне проекта:

```bat
start.bat
```

**macOS / Linux** — запустите скрипт (сделайте его исполняемым один раз, если нужно):

```sh
chmod +x start.sh   # один раз
./start.sh
```

Оба скрипта делают одно и то же:

1. переходят в папку скрипта (корректно работает и при запуске из другой директории);
2. проверяют, что установлен Node.js >= 22.5 (иначе — понятное сообщение со ссылкой на https://nodejs.org/);
3. создают `.env` из `.env.example`, если `.env` ещё нет;
4. если нет `node_modules` — выполняют `npm install`;
5. запускают сервер и клиент.

Windows дополнительно открывает браузер на `http://localhost:5173/` и показывает меню
(перезапуск, остановка, автозапуск при входе в систему — `start.ps1` управляет этим по PID
портов 3001/5173). В macOS/Linux сервисы работают в foreground, остановка — `Ctrl+C`.

Проект полностью переносим: база (`data/`), вложения и логи лежат внутри папки проекта,
пути строятся относительно самого проекта, поэтому папку можно целиком переносить между
дисками и операционными системами без потери данных.

### Если файлы не запускаются

Скачанный из интернета архив (ZIP) Windows часто помечает как «заблокированный» —
после распаковки скрипты из него могут открываться и сразу закрываться или не запускаться
вовсе. Перед распаковкой выполните:

1. кликните по архиву правой кнопкой мыши и выберите **«Свойства»**;
2. на вкладке **«Общие»** поставьте галочку **«Разблокировать»**;
3. нажмите **«ОК»**;
4. после этого разархивируйте папку и запускайте файлы как обычно.

## Команды

| Команда | Что делает |
|---|---|
| `start.bat` (Windows) | Bootstrap (Node.js-проверка, `.env`, `node_modules`) + умный фон-запуск с меню и автозапуском |
| `./start.sh` (macOS/Linux) | Bootstrap (Node.js-проверка, `.env`, `node_modules`) + запуск dev-серверов в foreground |
| `start.ps1` | Launcher под Windows: порты, фоновый старт, меню, автозапуск (используется `start.bat`) |
| `npm run dev` | concurrently: сервер (`tsx watch`, `127.0.0.1:3001`) + Vite (`http://localhost:5173/`) в foreground |
| `npm run build` | сборка клиента (`client/dist`) и сервера (`server/dist`) |
| `npm test` | vitest: серверные + клиентские тесты |
| `npm run lint` | eslint (`server/src`, `client/src`) |
| `npm run start` | production single-port: Fastify + статика клиента на одном порту 3001 |
| `npm run backup` | консистентный бэкап БД (`VACUUM INTO`, включает WAL) |

## Стек

- **Монорепозиторий**: npm workspaces `client/` + `server/`.
- **Клиент**: React 19, Vite, Tailwind CSS 4, TypeScript, Recharts, Tiptap (rich text в дневнике).
- **Сервер**: Fastify 5 + встроенный `node:sqlite` (`DatabaseSync`), Playwright для скрейпа курсов.
- **Деньги**: хранятся в минимальных единицах валюты (1/100) — без `float`; конверсия в USD по курсу, зафиксированному на дату записи.

## Конфигурация

Переменные окружения описаны в `.env.example` и при первом запуске копируются в `.env`:

- `PORT` — порт API-сервера (по умолчанию `3001`);
- `NODE_ENV` — `production` включает раздачу собранного клиента на том же порту;
- `POKERDOM_MIRRORS` — список зеркал PokerDom для курса USD->RUB (через запятую).

Секретов в проекте нет; `.env`, база данных (`data/`) и логи (`logs/`) в git не попадают.

## Структура

```

server/   Fastify API, сервисы, миграции node:sqlite, парсеры турниров
```
