# Poker CRM

Персональный локальный веб-кабинет для покерной бухгалтерии одного пользователя:
румы, балансы и сессии, транзакции (депозит/вывод/перевод/казино), импорт турниров,
статистика (график профита как в SharkScope + календарь активности), цели с дневником
и трекер привычек. Тёмный минималистичный интерфейс, подписи на русском.

## Быстрый старт

Для Windows достаточно запустить один скрипт в корне проекта:

```bat
start.bat
```

Скрипт сам подготовит окружение и запустит приложение:

1. переходит в папку скрипта (корректно работает и при автозапуске);
2. создаёт `.env` из `.env.example`, если `.env` ещё нет;
3. если нет `node_modules` — выполняет `npm install`;
4. запускает сервер и клиент, открывает браузер на `http://localhost:5173/`.

Дальше появится меню: перезапустить сервисы, остановить их, включить/выключить
автозапуск при входе в Windows или выйти (`start.ps1` управляет этим по PID портов).

Требования: **Windows** и **Node.js >= 22.5** (`node -v`).

## Команды

| Команда | Что делает |
|---|---|
| `start.bat` / `start.ps1` | Bootstrap (`.env`, `node_modules`) + умный фон-запуск с меню и автозапуском |
| `npm run dev` | concurrently: сервер (`tsx watch`, `127.0.0.1:3001`) + Vite (`http://localhost:5173/`) в foreground |
| `npm run build` | сборка клиента (`client/dist`) и сервера (`server/dist`) |
| `npm test` | vitest: серверные + клиентские тесты |
| `npm run lint` | eslint (`server/src`, `client/src`) |
| `npm run start` | production single-port: Fastify + статика клиента на одном порту 3001 |
| `npm run backup` | консистентный бэкап БД (`VACUUM INTO`, включает WAL) |

## Стек

- **Монорепозиторий**: npm workspaces `client/` + `server/`.
- **Клиент**: React 19, Vite, Tailwind CSS 4, TypeScript, Recharts, Tiptap (rich text в дневнике).
- **Сервер**: Fastify 5 + встроенный `node:sqlite` (`DatabaseSync`), Playwright для скрейпа курсов.
- **Деньги**: хранятся в минимальных единицах валюты (1/100) — без `float`; конверсия в USD по курсу, зафиксированному на дату записи.

## Конфигурация

Переменные окружения описаны в `.env.example` и при первом запуске копируются в `.env`:

- `PORT` — порт API-сервера (по умолчанию `3001`);
- `NODE_ENV` — `production` включает раздачу собранного клиента на том же порту;
- `POKERDOM_MIRRORS` — список зеркал PokerDom для курса USD->RUB (через запятую).

Секретов в проекте нет; `.env`, база данных (`data/`) и логи (`logs/`) в git не попадают.
